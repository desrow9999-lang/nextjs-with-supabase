```text
タイトル：ただ、生きているだけで満点の日々があっていい

「頑張って」
その一言が、かつての私メルトダウン寸前の心をどれだけ追い詰めたか分からない。

うつ病というトンネルに入ったとき、世界の色がすっぽりと抜け落ちた。朝起きること、カーテンを開けること、ご飯を食べる選択をすること。そのすべてが、まるで富士山を素手で登るような途方もないエネルギーを必要とした。

布団の中で天井を見つめながら、「今日も何もできなかった」と自分の価値をゼロに数える。そんな日々が続いた。

でも、ある日、カウンセラーの先生がこんなふうに言ってくれた。
「今日、布団から出られなかったとしても、あなたは一日中、病気と戦っていたんですよ。だから、それで十分です」と。

その言葉は、乾ききったスポンジに水が染み込むように、すうっと心にしみた。

うつ病の当事者に寄り添うとき、私たちはどうしても「元の元気な姿」をゴールにしてしまいがちな。早く治してほしい、いつもの笑顔に戻ってほしい。その願いは愛情の裏返しであるけれど、当事者にとっては「今のダメな自分を否定されている」ように感じてしまうこともある。

だからこそ、ただ「そこにいてくれること」を許容する空間が必要なのだと思う。

何かを生産しなくてもいい。
未来の計画を立てられなくてもいい。
ただ息をして、今日をやり過ごす。
そんな「最低限」に見える日常こそが、うつ病を抱える人にとっては命がけの営みだ。

もし今、これを読んでくれているあなたが、深い闇の中にいるのなら伝えたい。
今日、何もできなくても、布団から一歩も出られなくても、あなたの価値が減ることは絶対にない。

「何者かにならなければいけない」という呪いを、少しだけほどいてみよう。
今日という日を生き抜いた自分に、「よくやったね」と小さな丸をつけてあげる。

焦らなくていい。
季節がゆっくりと移り変わるように、あなたの心も、あなたのペースでしか春を迎えないのだから。

今日も、ただ、生きているだけで満点。
そう思える優しさが、あなたと、あなたの隣にいる大切な人の心を温めてくれますように。
```
